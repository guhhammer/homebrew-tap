# guhhammer's Homebrew tap

```
brew install guhhammer/tap/lore
```

- **lore**: every command you can type, A to Z, with an offline page for
  each. https://github.com/guhhammer/lore

The formula is made in lore's repository (`packaging/homebrew/lore.rb`,
filled in by `packaging/update.sh` after each release) and copied here.
